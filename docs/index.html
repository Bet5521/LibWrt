1连接你的仓库

第一次用？点开看操作步骤
  1. 本页默认指向 Bet5521/LibWrt（本项目仓库），无需 Fork 也能用。
  2. 如果你有自己的 fork：把仓库地址改成 你的用户名/LibWrt 即可。
  3. 生成 Token：经典 Token（勾选 repo + workflow）↗ 或 细粒度 Token（需 Actions: Read and write）↗
  4. 把 Token 填到下面 → 点「验证连接」→ 看到绿色对勾就能开始编译。
  5. Token 只存在你自己浏览器的 localStorage，本页不联网上传、不经任何中转服务器。
